# 食物热量秤

记录饮食、计算热量与营养、标识升糖指数（GI/GL），并支持**参照物标定拍照测重**。

纯前端单文件应用，无后端、无依赖、不联网、不上传任何数据。所有记录保存在浏览器本地。

## 功能

- **食物库**：1729 种食物，含别名检索（约 5000 个可检索词），覆盖主食、肉类、水产、蛋奶豆、蔬菜、水果、零食、饮品、调味、菜肴十大类
- **野菜/山野菜**：香椿、地软（地皮菜）、蕨菜、马齿苋、蒲公英、苦菜、灰灰菜、榆钱、槐花、车前草、鱼腥草、紫苏、藿香、荆芥、艾草、枸杞叶、刺嫩芽、马兰头、芦蒿、莼菜、蒲菜、藕带、菊花脑等 60+ 种
- **地方特色菜**：东北、川渝、粤港、江浙沪、湘、西北、云贵等地菜肴 250+ 道；地方特色主食小吃 70+ 种
- **生熟/部位变体**：按生/蒸/煮/烤/煎/炸、干制/泡发区分（如 大米生 346 千卡 vs 大米蒸 116 千卡，木耳干 265 vs 木耳泡发 27）
- **品牌成品**：涵盖主流茶饮/咖啡连锁（瑞幸、星巴克、喜茶、奈雪、蜜雪冰城等）、西式快餐（麦当劳、肯德基、汉堡王、必胜客等）、包装零食与调味品的具体产品
- **热量与营养**：热量、蛋白质、脂肪、碳水、膳食纤维、钠，按实际克重换算
- **升糖指数**：GI 分级（低/中/高/无碳水/暂无数据），可筛选
- **血糖负荷**：GL = GI × 可利用碳水 ÷ 100，并按餐食汇总
- **拍照测重**：放参照物（硬币/银行卡）拍照 → 标定比例 → 框选食物 → 填厚度 → 算出重量
- **今日统计**：按天汇总，支持删除单条与导出 CSV
- **⭐ 常用收藏**：把常吃的食物点 ☆ 收藏，顶部一键添加，不用每次搜索
- **＋ 自定义食物**：库里没有的自己录一个（填每 100g 营养数据），录一次以后就能搜到，且参与热量/GI/测重全部计算
- **数据备份**：一键导出全部数据（记录 + 收藏 + 自定义食物）为 JSON，换设备/浏览器时导入恢复；导入支持「合并」和「覆盖」两种方式

## ⚠️ 关于「估算值」标记

品牌成品的配方**不公开**，且会随产品调整而变化。因此：

- 凡带 **`≈ 估算值`** 角标的条目，数值是**按同类产品的成分推算**的，不是品牌官方数据
- 这类条目**不标注 GI**（配方不公开，GI 无从得知，编一个会误导）
- 使用这类条目时请把它当作量级参考，别当作精确值

有官方食物成分表依据的条目（如米饭、鸡胸肉、苹果）不带此标记。

## 数据来源

- 营养数据：《中国食物成分表（第 6 版）》、USDA FoodData Central
- GI 数据：Atkinson 等《International Tables of Glycemic Index》(2021)、《中国食物成分表》2004 附录

数据为每 100g 可食部的典型值。GI 受品种、成熟度、烹饪方式影响较大，仅供参考。

## 重要说明

- **照片测重存在误差**，通常在 ±25%~40%。它能给出量级判断，**不能替代厨房秤**。
- 所有指标**仅供饮食记录参考，不构成医疗或营养建议**。GI 相关数据不适用于糖尿病诊断或用药调整，请遵医嘱。
- 数据保存在浏览器 localStorage，**不会上传到任何服务器**。清理浏览器数据会丢失记录。

## 本地使用

直接双击 `index.html` 用浏览器打开即可。

或启动本地服务器（手机可通过同一 WiFi 访问）：

```bash
node serve.js
```

## 部署

本仓库可直接用于 GitHub Pages：`index.html` 是入口文件。
